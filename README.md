# Responsive Web Design

A responsive front-end website developed using **HTML, CSS, and JavaScript** to practice modern web page structure, responsive layouts, styling, and basic user interaction.

## Features

- Responsive navigation bar
- Hero section with gradient background
- Service cards
- Card hover animations
- Image gallery
- Image hover effects
- Contact form interface
- Light and dark mode toggle
- Responsive layout for smaller screens
- Styled buttons and interactive elements
- Footer section

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Flexbox
- CSS Media Queries
- CSS Transitions

## Responsive Design

The website uses CSS media queries to adapt its layout for different screen sizes.

On smaller screens:

- Service cards are displayed vertically
- Gallery images are arranged vertically
- Navigation elements adjust to the available screen space

## Dark Mode

The website includes a JavaScript-powered theme toggle that allows users to switch between light and dark modes.

JavaScript dynamically adds or removes the `dark` CSS class from the page and changes the theme button icon accordingly.
